# 🛡️ Incident Tracker & Postmortem Tool

> Una herramienta de ingeniería para equipos que priorizan la resiliencia y la mejora continua.

Este proyecto no es solo un gestor de tickets; es una plataforma diseñada bajo los principios de **Site Reliability Engineering (SRE)** para documentar, analizar y prevenir la recurrencia de fallos críticos en sistemas productivos.

## 🚀 Filosofía de Diseño
* **Blameless Culture:** Fomenta el análisis técnico sobre la búsqueda de culpables.
* **Actionable Insights:** Cada postmortem debe generar "Action Items" vinculados a tareas reales.
* **Observabilidad:** Seguimiento visual de la salud de los servicios a través del tiempo.
